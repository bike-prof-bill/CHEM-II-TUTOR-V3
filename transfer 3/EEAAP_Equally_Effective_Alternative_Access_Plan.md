# CHM 212 Guarded Tutor — Equally Effective Alternative Access Plan

7 October 2026 · prepared by the instructor-developer

## Purpose and contacts

Any CHM 212 student who cannot use part of the tutor gets an equally effective alternative within two business days of asking, with no loss of credit. The plan covers the gaps listed in the tutor's Accessibility Conformance Report of 7 October 2026 and any barrier a student reports that the report missed.

## Barriers and alternatives

Each known gap has an alternative available today; if none suits a student, the whole tutor has one (last row).

| Barrier | Who it affects | Alternative available now |
| --- | --- | --- |
| Plots have no text alternative | Blind and low-vision students | The instructor sends that problem's measured points and fitted line as a text table. Every problem's data is stored with it, so this takes minutes. |
| Speaker not announced in chat | Screen-reader users | Messages alternate tutor, student; on request the instructor sends the session as a labeled text transcript. |
| 26 symbol keys before the message box; no skip link | Keyboard and screen-reader users | Screen-reader form-field navigation (F in NVDA, the VoiceOver rotor) jumps straight to the message box. Symbols can also be typed as plain text (dH, T2, ln, exp). |
| Focus not moved to the notebook card | Screen-reader users | The card's text is announced. Its prompt can also be sent by the instructor, and the header's Notebook link opens the same notebook. |
| "Open notebook" button nested in a link | Screen-reader users | The header's Notebook link opens the same notebook. |
| Sideways scroll at 320 px | Students using high zoom on a phone | Landscape orientation, or a tablet or computer; content is not lost, only scrolled 21 px. |
| Low-contrast field borders | Low-vision students | The focus outline is high contrast; operating-system high-contrast modes draw borders. |
| Plot tooltips cannot be dismissed | Low-vision and keyboard users | Values are in the text table above. |
| Session ends after 6 idle hours | Students with extended-time accommodations | The instructor reopens the attempt or records it as complete; no credit is lost. |
| How equations are read aloud is not yet tested | Screen-reader users | If typed or pinned equations are unclear, the same problems are worked by email or in office hours (below). |
| The course notebook (a Google product) | Any student who cannot use it | The instructor gives the matching section of the OpenStax Chemistry 2e text, which is accessible, or explains the concept directly. |
| **Any part of the tutor, or all of it** | Any student | The same problems in an accessible document: scenario question, problem, required rearrangement and answer, completed by email, in office hours, or with a reader or scribe. The problem generator prints any problem with its answer key, so the student works the same problems, in the same steps, for the same credit. |

## How a student gets help

1. The student emails the instructor or tells the accommodations office what is not working. No documentation is needed to ask.
2. Within two business days, the instructor and student agree on an alternative from the table above, or a new one.
3. The instructor provides it: a data table, transcript, accessible problem document, or a meeting.
4. The student completes the work the agreed way. Deadlines move by the time the alternative took to arrive.
5. The instructor logs the barrier and adds it to the conformance report's gap list if it was not already there.

The course syllabus and the tutor's opening page will both state this process and the contact address.

## Grading and credit protections

A student using an alternative earns credit on the same terms as one using the tutor.

- Same problems, same required steps, same answer key, same credit.
- An attempt cut short by an accessibility barrier is not counted as a wrong try and does not lose credit.
- Wrong-try limits in the tutor (two tries, then a refresher) are applied in the alternative only if they help the student, and are waived on request.
- Using an alternative is never visible to classmates. If a study is approved, these records are flagged so they are analyzed or excluded fairly, never counted as lower performance.
